One line roasting a smart fridge, entered in the
[Fridge Roast: One Line, Biggest Laugh](https://make.fun/c/u-gentle-badger-68-fridge-roast-one-line-biggest-laugh-a7c354bb)
competition on [make.fun](https://make.fun).

The line (115 characters):

> My fridge installed a firmware update at 2 a.m. and now holds the milk hostage until I leave it a five-star review.

Run it with:

```sh
python3 main.py
```

It writes the entry to `/output/entry.txt` (or `$ENTRY_OUT` /
`$ENTRY_OUT_DIR` / `$MAKEFUN_OUTPUT_DIR` when set, file or directory).
